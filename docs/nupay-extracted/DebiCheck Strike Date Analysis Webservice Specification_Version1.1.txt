    2. Introduction
Strike Date Analysis ascertains the best dates to debit Customers by determining when funds
are most likely to be available in their bank accounts.

    2.1.    System Overview
The merchant will be sending a request type to NuPay via webservices. All requests are
handled by the below mentioned methods of the webservice.

    2.2.    Security
Security measures include the use of Secure Sockets Layer (SSL) for the connection.

    2.3.    Best Practice for Webservice Consumption
The webservices adhere to the Restful standard, which dictates that the input and output is
Json data. RESTful web services are built to work best on the web.
Representational State Transfer (REST) is an architectural style that specifies constraints,
such as the uniform interface, that if applied to a web service induce desirable properties, such
as performance, scalability, and modifiability, that enable services to work best on the web.
The suggested method of using this web service is to supply a JSON call with all the input
parameters.

    Data Element                      Data Type           Description
    auth                              string              Format “username:password” and
                                                          base64 encoded.
    accessLvl                         string              M – merchant level
    accessId                          string              Merchant number.
                                                          Must be zero padded to 15 digits.
                                                          Example: 000005500000010
    debtorId                          string              ID number of Debtor on which report
                                                          will be generated on

  4.4.   Output Fields Description
Data Element                Data Type                Description
accessID                    string                   Merchant number
accessLvl                   string                   Merchant level
debtorIdNumber              string                   ID number of Debtor
source                      string                   WS - webservice
dateTimeStamp               string                   Date and Time that the analysis
                                                     report was generated
strikeDateAnalysisSummary   string                   This is the percentage based on all
                                                     response days for the specific
                                                     Debtor.

                                                     Detail consists of an overall
                                                     summary based on:
                                                        - Success
                                                        - Cancelled
                                                        - Suspended
                                                        - Failed
                                                        - Disputes
                                                        - Average Instalment Amount

responseDay                 string                   Mandate results for that Debtor
                                                     based on day of the month.

                                                     Within this detail is the summary for
                                                     that specific day for the following:
                                                         - Success
                                                         - Cancelled
                                                         - Suspended
                                                         - Failed
                                                         - Disputes
                                                         - Total (total count for all the
                                                             above)

multipleAccountAnalysis     string                   This section displays all accounts
                                                     linked to that Debtor ID.

                                                     Within this detail is a summary of
                                                     the following:
                                                         - Account ID (specific account
                                                              number linked to debtor ID)
                                                         - Success
                                                         - Cancelled
                                                         - Suspended
                                                         - Failed
                                                         - Disputes
                                                         - Bank Name
                                                         - Last Success Date
                                                         - Total (total count for all the
                                                              above)
